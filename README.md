# Taskwolf - Server - CLI

[![CI](https://github.com/taskwolf-net/taskwolf-server-cli/actions/workflows/ci.yml/badge.svg)](https://github.com/taskwolf-net/taskwolf-server-cli/actions/workflows/ci.yml)

This application can be used by customers to automate their servers. It is used by customers to change settings for the server service and to access information about the service.
